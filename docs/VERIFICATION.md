# 근거 검증 보고서

서비스 화면, AI 답변, 기획서, README에 들어간 사실·숫자·인용을 하나씩 원본과 대조했습니다(2026-11-24).
각 항목은 아래 셋 중 하나입니다.

- **확인**: 공식 자료, 원문 기사, 공공데이터에서 같은 값을 확인했습니다.
- **수정**: 근거와 다르거나 과장된 부분을 발견해 고쳤습니다.
- **가정**: 공개된 근거가 없어 가정으로 두었고, 화면과 문서에 가정이라고 밝혔습니다.

숫자 가운데 코드로 계산되는 값은 자동 테스트(`tests/`, `pipeline/tests/`)가 매번 다시 계산해 같은지 확인합니다.

## 5. 아직 남은 한계

- 휠체어석 세부 좌석 번호와 앞 펜스 높이는 실측 자료가 없습니다. 기관 상세 배치도나 현장 확인으로 보정해야 합니다.
- 좌석 높이 0.40m와 '매진 가정'은 공개 근거가 없는 가정입니다.
- 역 출구 엘리베이터 등 OSM에 없는 시설 정보는 '미확인'으로 표시하고, AI는 단정하지 않고 문의처를 안내합니다.
- 1인칭 화면의 출연자·조명·전광판은 공연 당일을 재현한 연출이며, 화면에 그렇게 밝혀 두었습니다.
